# 脚本注释与桌宠重构计划

## 已确认的注释规范

- 范围：`Assets/Script` 下的项目脚本，排除第三方插件和生成代码。保持 UTF-8 编码，遵循 `.editorconfig`。
- 使用成对的 `#region` / `#endregion` 按功能划分；不再使用长横线分隔注释，不为每个方法单独建立区域。
- 类说明采用多行 XML 文档：第一行写中文类名，第二行以 `- ` 开头说明精炼职责。
- 每个方法（含生命周期、私有方法和协程）均有 `<summary>`；参数逐一填写 `<param name="实际参数名">`；非 void 返回值填写标准 `<returns>`，协程说明其迭代器所控制的流程。
- 文档确需分段时使用 `<para>`；需要简单换行时可用 `<br/>`。泛型参数使用 `<typeparam>`。
- Inspector 可编辑字段使用 `[Tooltip]` 说明用途、单位或约束；私有运行状态及其他重要成员使用单行 XML `<summary>`。
- 方法内部保留有价值的 `//`，解释关键分支和约束，避免逐句翻译代码。说明统一使用简体中文，标识符保持原样。
- 先核实逻辑再写注释，不把当前实现没有提供的能力描述成保证。注释整理不改变方法签名、序列化字段、数值、调用次序或游戏逻辑。

- 补充：Tooltip 仅用于实际参与 Inspector 序列化显示的字段，包括受支持的 public 实例字段及显式序列化字段；不用于属性、静态/常量/只读字段、未序列化私有缓存或不显示的字段。不为了添加 Tooltip 而改变字段访问级别或序列化方式。当前 RandomEvent 只由未序列化的私有列表持有，其内部字段使用 XML 说明。
